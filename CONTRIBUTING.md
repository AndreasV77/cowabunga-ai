# Contributions

Bug reports, questions and suggestions are welcome through GitHub Issues.
Please do not post credentials, private drafts, listening logs or other personal
data. A report should describe the behavior, expected result and reproduction
steps using non-sensitive sample data where possible.

External code contributions are not accepted at this stage. Contribution terms
must first establish the rights required for the project's personal-use license
and separately authorized integrations. Sending a pull request does not transfer
ownership, and the repository license alone is not treated as permission for the
maintainer to relicense someone else's code. Please discuss a proposed change
before submitting code.

Reference-source suggestions should include the original URL, license, relevant
version or revision, and the limits of any claimed evidence. Third-party source
rights remain separate from the project code license.

For permission to integrate or offer the tool to others, see
[licensing guidance](docs/licensing.md). Opening an issue is not authorization.
